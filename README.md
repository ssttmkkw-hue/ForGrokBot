# 打砖块

一个纯静态的浏览器打砖块小游戏。用 HTML5 Canvas 和原生 JavaScript 写成，不需要构建，打开就能玩。

在线地址：<https://ssttmkkw-hue.github.io/ForGrokBot/>

## 玩法

移动挡板接住小球，把砖块全部打掉即可过关。一共 5 关，每进入下一关，球都会更快。你有 3 条生命，球落出画面底部就失去一条生命；生命用尽则游戏结束，通关全部关卡即获胜。

小球打在挡板上的位置会改变反弹角度：打在中间更接近竖直向上，打在两侧则飞向对应方向。

## 操作

- 鼠标：移动控制挡板
- 触摸：在画面上按住左右滑动（手机）
- 键盘：← → 移动挡板
- 空格：开始、发球、暂停、继续，或在结束后重新开始
- P：暂停 / 继续
- 画面右上角「暂停」：用触摸时也可以暂停或继续

开始画面提示为「点击或按空格开始」。

## 本地打开

用浏览器直接打开仓库根目录的 `index.html` 即可。也可以在仓库目录启动任意静态文件服务后访问。
